# 잠꾸러기 꼬물이의 엄마 찾기

Python `tkinter`로 만든 시간 제한 탐험 게임입니다. 꼬물이가 바닷속 여러 장소를 탐험하며 단서를 모아 엄마를 찾아요.

## 게임 방법

- 시작을 누르고, 8곳의 장소를 탐험해 단서 3개를 모으세요.
- 제한 시간은 60초입니다. 이동할 때마다 시간이 줄어듭니다.
- 탐험 중 상어를 만나면 3초 안에 숨기 버튼을 누르세요.
- 이동으로 피로가 쌓이면 기지개를 켜서 피로를 줄일 수 있지만, 시간이 소모됩니다.
- 고래를 만나면 피로가 추가됩니다. 시간이 끝나기 전에 단서를 모으면 승리합니다.

## 실행 방법

Python 3이 설치된 환경에서 실행하세요. 별도의 패키지 설치는 필요하지 않습니다.

```bash
python game.py
```

`tkinter` GUI가 지원되는 데스크톱 환경이 필요합니다. Windows에서는 기본 Python 설치에 포함되어 있습니다.
